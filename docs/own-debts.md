# 本仓自己的欠账表

> 这是闸的源头仓**自己**的欠账表,不随安装器发给别的仓。`gate-install.json` 的 `debtTable` 指到这里,
> 所以 `batch-goal --settle`(登记欠账)、开批时列到期项、欠账表结构核、写前核都读写本文件。
> 随包发的 `docs/gate-debts.md` 是给安装方的空示例表,里面不放本仓的欠账(自测钉着它在任何批号下都没有到期项)。
> 格式与 `docs/gate-debts.md` 相同:每条欠账必须带失效期(`≤<批号>`);表体内不许留空行;新行加在表头下第一行。
