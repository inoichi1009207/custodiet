# 闸欠账表

> 示例文件。**MF 项**(规则型 memory 没交代执行面)与 **SE 项**(自查出错没写「闸怎么拦」)的 law 锚点指向本文件的「在账欠账」一节;
> 它们给出的出路之一是「往这里新登记一个 D 号行」。T 项会核每条登记是否带失效期。
> 立此表的理由(源项目,2026-08-20):对「处置」的定义若是「改了**或**登记了」,登记就会被当成达标——
> 所以每条欠账**必须带失效期**,到期未兑现即回到在账,不是自动消失。
> 本文件是台账,不是法源;规则住 `docs/laws/`,判据住闸引擎。
> 表体内不许留空行(空行会把表断成两张、后半截丢表头);新行加在表头下第一行。

## 计量单位

失效期用**批次数**(`≤<批号>`),不用日期;「N 批内」从登记批号起算。
