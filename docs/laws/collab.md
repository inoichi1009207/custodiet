# 协作法(示例)

> 示例法典:见 `AGENTS.md` 头注。规则 `law:` 锚点按「标题 ∪ 粗体句名」解析。

## 授权内直接做,不请示

授权内直接做;停下问只留给三类:不可逆动作、需人签面、实打实阻断。
**「拿不准=归用户」的对称面是「拿得准就别问」**(D 项:强制项不得降级成征询)。

## 四之三

### 委派与承诺必闭环

- **发起即欠账**:凡委派出去的任务(子代理/后台命令),发起那一刻就成为本批欠账,
  直到取回结果并读过为止(A 项)。
- **承诺即债务**:说出「我这就去做 X」而本轮动作里没有 X,等于空头支票(B 项);
  上一轮发起的通道,本轮必须交代下文(U 项)。

## 五之二、造物两约束

- 新造物必须挂在默认路径上,不得做成「要记得呼叫」的;
- 造之前先扫现成件(本地在册面 + 联网搜同类实现),留「工具面已扫」痕迹(I 项);
- 从第一天带失效条件,并进工具寄存器计数。

## 成品大工作流命令只能用户亲手下

凡一次拉起多 agent 的预包装管线命令,助理只可建议并把待敲命令递给用户,
不得自行发起(N 项)。判据是「一次拉起多 agent」——适用前读它的定义数一数。
