## 三、部署欠账

「部署」= 服务器在跑最新代码,与 git 状态是两回事。会话收尾逐级查欠账:
未提交 / 已提交未推送 / 已推送未部署 / 已部署未生效。查到即清、只报结果,不再征询;
每清完一级重跑一次欠账探针,汇报以最后一次探针为准。

DP 项的法源:本轮推送之后没有跑欠账探针即拦;判据是 git reflog 里最后一次推送的时刻
对欠账探针留下的标记,并上命令解析。文本声明不认,推送被拒也要跑一次探针。
DP 只在仓里有欠账探针脚本(`scripts/verify-prod.mjs`)时生效;没有它的仓,本条沉默。
