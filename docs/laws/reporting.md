# 汇报法(示例)

> 示例法典:见 `AGENTS.md` 头注。

## 「完成」靠核对不靠断言

经脚本/管线产生的写入,写后要回读确认真的落盘(M 项);
「我说我做了」不是证据,动作面上的回读才是。

## 完成性断言须与未覆盖栏一致

同一段话里既说「全部执行完毕」又登记欠件,两者必须对得上(F 项)。

## 未被机器直证的因果断言过独立复核

「A 导致 B / 根因是 X」类断言,要么给一条能直接看到的机械判据(探针/命令),
要么走独立复核(跨模型或找判据的流程);两个都没有就不许当结论用(E0/E1/E2 三项)。

## 关账前自审一遍

关账自审的可核项走动作面判据:①新造物入册 ②寄存器行带失效条件 ④触闸机件必跑自测
(G 项);不可机器核的项归人审。

## 承重面三通道必跑

承重面的批,收账前三条独立通道各至少一遍:跨模型复核(判「我说的对不对」)、
只读子代理(判「我漏了什么」)、联网先例(判「业界踩过没有」)(P 项)。
计数只认动作面,文本提及一次都不算。

**按 diff 事实分档**:本批承重面改动若**全是轻档**,跨模型与外部先例两条免跑,
独立视角照跑(闸引擎面的红队不受影响)。轻档只有一类:测试文件(JS/TS 的 `*.test.*` / `*.spec.*`、`*.selftest.mjs`、
`.nlpm-test/` 顶层的文件,只新增或修改,按文件名认——被生产代码 import 的测试名文件是已登记残余)。
代码注释不分档——工装头注是规则载体,改它与改代码同审;文案不分档——单字替换分不出笔误与改规则。
判据只认 git 改动清单,唯一实现 `scripts/lib/gate-difftier.mjs`;触发层 = P 项 `tierFilter`;
失效条件 = 轻档放行的批次事后被证实改了行为 ⇒ 该类撤回重档并复议。

**红队回件的分拣与停止**:闸引擎批的红队回件逐条分两档,**当批必修只有两类**:
① 诚实写法下的**漏放**,且在真实转录里出现过,或由本批新代码引入;
② 诚实节奏下的**误拦**,且由本批新代码引入(含合并裁决引入的回退)。
其余(疑似、语料未见的老问题、既有设计、故意伪造)一律登记进欠账表并给失效期,不阻塞关账。
修完后的复核红队只打本次修改的部分。漏放与诚实误拦同价、故意伪造不计——变的只是「哪些当批修」。
触发层 = `_gate-bypass-hunter` 输出格式里的「来源」「形态」两栏,派出方据此分拣;分拣本身无机器判据,在汇报里逐条写出归档。
失效条件 = 登记进欠账的某条在失效期前被证明造成过一次真实漏放 ⇒ 本条复议。

## 开工先立完成条件

凡要动工作面(写文件/提交)的活,开工时先写下这一批算什么才叫完成,收尾时逐条对照:
`node --no-warnings scripts/batch-goal.mjs --arm <批号> --cond "…"`;收尾逐条写
「条件N:达成/未达成/不适用」加一句证据,办完 `--clear`。纯问答与纯调查不必立。
本批提交信息里像有已签的决定、而决定清单为空时,AD 项提示用 `--decision` 登记(只提示,不阻断)。

## 交付物四眼

对外交付物(方案/报告/呈签件)发出前过一道独立复核(W 项)。
